# 🕌 نقشه و راهنمای جامع اماکن مذهبی و مراسمات کهن‌شهر دزفول
> **Dezful Religious Heritage, Mosques, Hussainiyas & Live Events Platform**

پلتفرم یکپارچه و هوشمند راهنمای مساجد، حسینیه‌ها، بقاع متبرکه و رویدادهای مذهبی شهر دارالمؤمنین دزفول؛ طراحی شده برای دسترسی آسان شهروندان و زائران به اوقات شرعی، برنامه‌های هیئات، اطلاعات معماری بومی نظیر شوادون و مسیریابی چندگانه. این سامانه با تلفیق فناوری‌های مدرن نقشه، تقویم شمسی جلالی و سیستم اعلان‌ها، تجربه‌ای پویا، سریع و در دسترس را برای تمام رده‌های سنی فراهم می‌آورد.

## ✨ ویژگی‌های کلیدی سامانه (Key Features)

- 🗺️ **نقشه تعاملی و پیشرفته (Leaflet & Custom Clustering):** تفکیک بصری مساجد، حسینیه‌ها و بقاع با استایل سفارشی آجری دزفول و محاسبه آنلاین فاصله با فرمول Haversine.
- 🏛️ **شناسنامه تخصصی شوادون‌شناسی و معماری بومی:** ثبت عمق شوادون‌ها، وضعیت تهویه طبیعی، دسترسی خنکای زیرزمینی در ایام تابستان و خوون‌چینی آجری.
- 🌙 **تقویم رویدادها و فید مراسمات لحظه‌ای:** اطلاع‌رسانی دعای کمیل، ندبه، محافل انس با قرآن، سخنرانان، مداحان و پخش زنده همراه با برچسب نذری و پذیرایی.
- 🧭 **مسیریابی هوشمند چندگانه:** اتصال مستقیم به اپلیکیشن‌های نشان، بلد، ویز و گوگل مپ با یک کلیک.
- 🏘️ **فیلتر محلات عرفی کهن‌شهر دزفول:** دسته‌بندی اختصاصی محلات تاریخی نظیر قلعه، کرناسیان، صحرابدر، سیاه‌پوشان، لوریان و کوپیته.
- ⏰ **اوقات شرعی به افق دزفول و آلارم اذان:** محاسبه دقیق اذان، قبله‌نما و نمایش لحظه‌ای باز یا بسته بودن درب اماکن.
- 🌓 **طراحی مدرن با دو حالت روشن و تاریک:** ترکیب رنگ‌های آجری اصیل (`#C26D47`) و ماسه‌سنگی دزفول (`#FAF7F2`) در تم روز و خاکستری عمیق در تم شب.
- 📱 **واکنش‌گرایی کامل و باتم‌شیت موبایل:** رابط کاربری کاملاً راست‌چین (RTL) همراه با تایپوگرافی چشم‌نواز قلم «وزیرمتن» (Vazirmatn).

## 🛠 استک فناوری (Tech Stack)

- ⚛️ **Frontend:** React 19, TypeScript, Vite, Tailwind CSS v4, Motion (Framer Motion), Lucide React
- 🗺️ **Mapping & GIS:** Leaflet.js, React-Leaflet, Leaflet.markercluster
- 📅 **Calendar & Date:** Date-fns Jalali (تقویم شمسی جلالی)
- 🗄️ **Backend & Database:** Express.js, Prisma ORM, SQLite / PostgreSQL
- ⚡ **Tooling & Runtime:** Bun / Node.js 18+, TypeScript (`tsx`), ESBuild, Prettier

## 🚀 نصب و راه‌اندازی گام‌به‌گام (Installation & Setup)

### ۱. کلون کردن مخزن
```bash
git clone https://github.com/your-username/dezful-religious-map.git
cd dezful-religious-map
```

### ۲. نصب پکیج‌ها و وابستگی‌ها
با استفاده از **Bun**:
```bash
bun install
```
یا با استفاده از **npm**:
```bash
npm install
```

### ۳. تنظیم متغیرهای محیطی
یک کپی از فایل `.env.example` ایجاد کرده و مقداردهی کنید:
```bash
cp .env.example .env
```

### ۴. راه‌اندازی پایگاه داده و بارگذاری داده‌های اولیه (Prisma)
```bash
# تولید کلاینت پریزما
npx prisma generate

# اعمال اسکیما روی دیتابیس
npx prisma db push

# بارگذاری اولیه مساجد، حسینیه‌ها و محلات کهن دزفول
npm run seed
```

### ۵. اجرای پروژه در حالت توسعه
```bash
npm run dev
# یا با بستر Bun:
# bun run dev
```

برنامه روی پورت **3000** به آدرس `http://localhost:3000` در دسترس خواهد بود.

## ⚙️ متغیرهای محیطی (Environment Variables)

| نام متغیر | توضیح | مقدار نمونه |
| :--- | :--- | :--- |
| `VITE_GOOGLE_AI_API_KEY` | کلید هوش مصنوعی دستیار کلاینت | `your_ai_key_here` |
| `DATABASE_URL` | آدرس اتصال به پایگاه داده Prisma | `file:./dev.db` یا `postgresql://...` |
| `PORT` | پورت وب‌سرور | `3000` |
| `NODE_ENV` | محیط اجرای برنامه | `development` / `production` |

```text
dezful-religious-map/
├── prisma/
│   ├── schema.prisma          # تعاریف مدل‌های پایگاه داده (Neighborhood, Place, Event)

│   └── dev.db                 # پایگاه داده SQLite محلی
├── src/
│   ├── components/            # کامپوننت‌های ماژولار UI
│   │   ├── common/            # کامپوننت‌های مشترک (دکمه، نشان‌ها و مودال‌ها)

│   │   ├── map/               # نقشه Leaflet، لایه‌ها و مارکرها
│   │   ├── modals/            # مودال‌های جزئیات مکان، ثبت مراسم و جستجو
│   │   └── navigation/        # منوی ناوبری موبایل و دسکتاپ
│   ├── constants/             # ثابت‌های رنگی و پیکربندی‌ها
```
